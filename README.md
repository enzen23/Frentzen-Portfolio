# Frentzen Ford Ochoa Portfolio V2

A static, recruiter-focused portfolio built from the supplied resume and portfolio.

## Free publishing
Upload the contents to a public GitHub repository and enable GitHub Pages from Settings > Pages > Deploy from branch > main > root.

## Notes
- No framework or paid hosting is required.
- Images are selected from the supplied portfolio PDF.
- Metrics and experience claims are based on the supplied resume.
- Add a LinkedIn URL and a direct resume PDF link before publishing if desired.
